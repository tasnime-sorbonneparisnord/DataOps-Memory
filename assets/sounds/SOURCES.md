# Sources des sons

Tous les sons de ce dossier (effets et musique) ont été **générés par programme**
(synthèse avec NumPy) spécialement pour DataOps Memory : aucun fichier externe,
aucune licence à respecter.

| Fichier | Moment |
|---|---|

| match.ogg | bonne paire |
| mismatch.ogg | mauvaise paire |

| win.ogg / lose.ogg | fin de partie |
